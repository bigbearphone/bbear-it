# BIGBEAR ONE DEMO v4

ปรับตาม Feedback ล่าสุด:
- Pop-up รายการค้างเมื่อเปิดระบบ
- Dashboard ทุกตัวเลขคลิก Drill-down ได้
- กราฟยอดขายรายวัน เปรียบเทียบเดือนก่อน
- Stock ทุกสาขาคลิกดูรายละเอียดได้
