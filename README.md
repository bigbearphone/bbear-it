# BIGBEAR BUSINESS SYSTEM

เว็บต้นแบบระบบคลังสินค้ากลาง สาขา Partner และรับเข้า-ขายออก สำหรับร้านหมีใหญ่ โมบาย

## เปิดใช้งาน
เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ หรืออัปโหลดโฟลเดอร์ทั้งหมดขึ้น GitHub Pages / Netlify / Vercel

## ฟังก์ชันในเวอร์ชันนี้
- Dashboard ภาพรวม
- คลังสินค้ารายเครื่องด้วย IMEI
- ระบบหลายสาขา
- ระบบ Partner
- รับสินค้าเข้า
- ขายสินค้าและตัดสต๊อก
- โอนสินค้าระหว่างคลังและสาขา
- รายงานยอดขาย
- เก็บข้อมูลใน LocalStorage
- ส่งออกข้อมูลเป็น JSON

## หมายเหตุ
เวอร์ชันนี้เป็น Front-end MVP ใช้งานบนเครื่องเดียว ข้อมูลเก็บใน Browser
ก่อนใช้งานจริงหลายคนพร้อมกัน ควรเชื่อม Backend, Database, Login, Role Permission และระบบสำรองข้อมูล
